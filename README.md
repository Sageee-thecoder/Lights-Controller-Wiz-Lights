# Lights-Controller-Wiz-Lights
A Pyhton program to control the bulbs of my room by Wi-Fi.

1. Make sure you have the `hand_landmarker.task` in your project folder.
2. Open CMD and do `pip install opencv-python numpy pyautogui pywizlight mediapipe` and press enter.
3. Open the file in some kind of file editor.
4. Change the IP's to your Wiz Bulb's IP addresses.
5. Save it.
7. And run the `ColorWheelBulbs.py` Pyhton file.
